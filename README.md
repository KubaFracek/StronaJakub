## About

This repository contains a collection of demo landing pages built for fictional companies, showcasing different visual styles and front-end techniques. Each project explores a distinct design direction — from dark-mode e-commerce to editorial layouts and glassmorphism UI.

All projects are built with pure **HTML, CSS & JavaScript** — no frameworks, no build tools, no dependencies.

## Running Locally

No build step required. Just clone and open:

```bash
git clone https://github.com/KubaFracek/StronaJakub.git
cd StronaJakub
# Open index.html in your browser
open index.html
```

Or use a local server (recommended for best results):

```bash
npx serve .
```
